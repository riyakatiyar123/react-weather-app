# React Weather Application

## Overview

The React Weather Application is a web application developed using **React.js** that provides real-time weather information for any city entered by the user. The application retrieves weather data from the OpenWeather API and displays it through a clean and responsive user interface built with Material UI.

---

## Features

- Search weather information by city name
- Display current temperature
- Display minimum and maximum temperature
- Display "Feels Like" temperature
- Display humidity
- Display current weather conditions
- Display an error message for invalid city names
- Responsive user interface using Material UI

## Installation

Clone the repository:

```bash
git clone https://github.com/riyakatiyar123/react-weather-app.git
```

Navigate to the project directory:

```bash
cd react-weather-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
